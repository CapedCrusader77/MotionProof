# Homepage assets (Blender pipeline)

Blender 5.2.2 LTS at `E:/Blender/blender.exe`. Run from the repository root.

| Step | Command | Produces |
|---|---|---|
| 1. Real data + variant geometry | `uv run python scripts/export_homepage_data.py` | `frontend/public/assets/motionproof/data.json`, `build/nominal`, `build/variants/{typical,p90,worst}` |
| 2. Interactive GLB + .blend | `blender -b --factory-startup -P assets/blender/homepage/build_scene.py -- <repo>` | `motionproof_homepage.blend`, `frontend/public/assets/motionproof/assembly.glb` |
| 3. Cinematic stills / WebM | `blender -b -P assets/blender/homepage/render_cinematic.py -- <repo> reveal\|finale [--still N] [--samples S] [--scale %]` | `renders/` |

## What is real and what is render-only

* **Engineering geometry** (`build_scene.py`, collection `Engineering`, exported to the GLB): the 20 components the
  MotionProof engine generates for the synthetic NEMA 17 planetary elbow, in the engine's own coordinates (mm, gearbox axis
  +Y, arm +X). Gears are pitch cylinders, as in the engine. Names, mass, group and body are carried as glTF extras.
* **Variants**: `typical`, `p90`, `worst` are real scenarios (S000606, S000739, S000750) of experiment EXP_001, sorted by
  `angle_error_max`. Their geometry is regenerated by `motionproof.reference.nema17_arm.write_geometry` with the scenario's own
  geometric parameter values, then stored as glTF morph targets (`variant_<id>`) on the nominal mesh (matched by proximity;
  worst match distance per part in `build/variant_deviation_mm.json`). Deviations are microns to tens of microns, so any visible
  difference is a magnification and must be labelled as one.
* **Clips**: `Explode` (axial, 120 frames) and `Run` (96-frame loop of the ideal 33:1 kinematics). These are kinematic
  animations, not simulation results. Dynamic response comes only from `data.json`.
* **Render-only** (`render_cinematic.py`, collection `RenderOnly`, never exported): gear teeth, housing cutaway, studio lights,
  floor, cameras. Not simulated by MotionProof.
